### Introduction
This project was inspired by the [Arch Wiki](https://wiki.archlinux.org/title/Router) guide on configuring a general-purpose router. The goal was to build a bare-minimum router from a clean Arch Linux installation, creating a system that is simple enough to reason about yet real enough to administer long-term. By prioritizing minimalism, the router serves as a focused environment for learning Linux system administration concepts while also conserving system resources. The emphasis is on understanding how each component fits together rather than adding features for convenience.
